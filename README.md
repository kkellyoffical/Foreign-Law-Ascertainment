# Foreign Law Ascertainment · 外国法查明

本项目由华东政法大学学生编写，源自**格致Globlex域外法智能查明平台**。

平台现已列入**中华人民共和国司法部法通网的友情链接**，可从[法通网](https://lexcom.12348.gov.cn/homepage)进入[平台网站](https://lawindex.kkcode.club)。

我们将主要的外国法查明框架及八个国别项目代码以 **Apache-2.0** 协议开源，供法律实务工作者、研究人员和开发者参考。希望这些探索能为外国法查明与法律人工智能研究提供一些具体的实现参考，也欢迎大家提出意见，交流改进。

本仓库保留国别项目的前后端、智能体、引用核验及数据库结构代码，用于代码展示与研究交流，不提供完整运行环境或部署教程。

## 发布范围

不包含出口管制、合同审查、统一门户、共享依赖、检索与采集服务、法律原文数据库、向量数据、模型权重或生产环境配置。部分导入、接口及素材引用因此需要在完整项目中解析，克隆本仓库不能直接启动完整平台。

发布前已移除原部署目录、旧运维说明和学校标识图片；数据库实例、配置文件及凭据文件的默认接入信息已脱敏。源码中保留的环境变量名称和通用权限逻辑用于说明接口与程序行为，不包含实际密钥或账号授权。

本仓库使用全新的提交历史，不携带原集成仓库的历史记录。
